# ChatBot com IA (Hugging Face)

Chatbot simples e prático em Python, integrado a **modelos de linguagem (LLMs) da Hugging Face**. Um exemplo direto de **IA aplicada**: conectar um modelo de linguagem a uma interface de conversa funcional.

## O problema que resolve

Mostra, de forma enxuta, como integrar um LLM a uma aplicação real para criar interação e atendimento automatizado — base para chatbots de suporte, FAQs inteligentes e assistentes.

## Funcionalidades

- Conversa em linguagem natural via API da Hugging Face
- Estrutura simples e fácil de adaptar a outros modelos
- Ponto de partida para soluções de atendimento com IA

## Tecnologias

- Python 3
- API da Hugging Face (Inference)
- `requirements.txt` com as dependências

## Como rodar

```bash
git clone https://github.com/David-Henrique-Cangiani/ChatBot-Local.git
cd ChatBot-Local

pip install -r requirements.txt
python chatbot.py
```

> **Token da API:** configure sua chave da Hugging Face em uma variável de ambiente (ex.: `HUGGINGFACE_API_TOKEN`). **Nunca** deixe o token escrito no código versionado.
